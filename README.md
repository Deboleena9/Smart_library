# Smart_library
Smart Library for academic library management.
Includes Features like:
* Admin section:
> * Adding students with corresponding Name, Registration number, and assign passwords.
> * Adding books with corresponding ISBN number and auther.
> * Issuing books to the students.
> * Can set default issueing period and the institution name to view in the website.

* Student section:
> * Able to see which book is currently issued to the student and when is the due date.
> * can see which book is currently available to borrow from the library.
